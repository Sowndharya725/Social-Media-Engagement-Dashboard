# 📊 Social Media Engagement Dashboard

## 📑 Project Overview
An interactive Power BI dashboard designed to track, analyze, and visualize key social media performance metrics across multiple platforms (Facebook, Instagram, YouTube).

## 🔑 Key Features
* **Key Performance Indicators (KPIs):** Total Posts, Total Reach (formatted dynamically with custom DAX), Total Likes, and Total Shares.
* **Content Engagement Analysis:** Breakdown of user interactions across Reels, Images, Carousels, Stories, and Videos.
* **Engagement Trend Analysis:** Time-series line analysis tracking daily interaction variations.

## 🛠️ Tools Used
* **Power BI Desktop**
* **DAX (Data Analysis Expressions)** - Custom metrics and data formatting
